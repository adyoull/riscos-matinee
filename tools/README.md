# tools

| File | What |
|---|---|
| `mksprites.py` | Draws `!Sprites` (the PlexRO icon, from shapes: our own picture) |
| `mkrozip.py` | A zip that RISC OS unzips with filetypes (copied from riscos-ffmpeg) |
| `check-stack-probes.py` | Every big stack frame is probed (`-fstack-clash-protection`) (copied from riscos-ffmpeg) |
| `check-unixlib.sh` | The program was linked with UnixLib 5.0.3.1 (from riscos-ffmpeg's, with a symbol check added) |
